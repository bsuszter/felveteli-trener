# Témakörök

Ez a könyvtár a Felvételi tréner magasabb szintű témaköreit tartalmazza.

- `helyesiras/` – a már működő helyesírási rendszer metaadatai;
- `szolasok/` – Szólások és közmondások, új fejlesztési ág.

A működő helyesírási fájlok egyelőre kompatibilitási okból nem kerültek át fizikailag ide. Az új témakörök már ebben a névtérben épülnek fel.
