# Gyakorlófeladatok – teljes bank

A `practice.js` fájlban aktív, közös helyesírási gyakorlóbank pedagógiai ellenőrző jegyzéke. A **félkövér** válasz a helyes.

## Felszólító mód

1. **Melyik mondat helyes?**  
   Küld el a levelet! / **Küldd el a levelet!**  
   _A küld ige d-re végződik, ehhez kapcsolódik a felszólító mód -d jele: küldd._

2. **Melyik mondat helyes?**  
   **Mondd meg az igazat!** / Mond meg az igazat!  
   _A mond felszólító módú, határozott ragozású alakja: mondd._

3. **Melyik mondat helyes?**  
   **Hagyj egy kis időt!** / Haggy egy kis időt!  
   _A hagy igéhez a felszólító mód -j jele kapcsolódik: hagyj._

4. **Melyik mondat helyes?**  
   Higyj nekem! / **Higgy nekem!**  
   _A hisz ige rendhagyó felszólító módú alakja: higgy._

5. **Melyik alak illik a mondatba? „___ le a neved!”**  
   Ír / **Írd**  
   _Az ír igéhez a -d jel kapcsolódik: írd._

5. A sportoló nagy **súlyt** emel. / A sportoló nagy sújt emel.

## Mássalhangzók és toldalékolás

1. **Lassan a testtel!** / Lassan a testel!  
   _A -val/-vel rag v-je teljesen hasonul a szó végi t-hez: test + vel → testtel._

2. **Játssza az eszét.** / Játsza az eszét.  
   _A játszik ige helyes alakja ebben a mondatban: játssza._

3. **szükség** / szügség  
   _A szükség szóban k-t írunk._

4. **kézzel** / kézel  
   _A kéz szóhoz kapcsolódó -val/-vel rag v-je teljesen hasonul: kéz + vel → kézzel._

5. **azzal** / azal  
   _Az az névmáshoz kapcsolódó -val/-vel rag v-je teljesen hasonul: az + val → azzal._
